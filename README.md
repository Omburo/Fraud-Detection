# Fraud-Detection
Mini project: Built and compared four machine learning classifiers — K-Nearest Neighbors, Decision Tree, Artificial Neural Network (MLP), and SVM — to detect fraudulent transactions in a 120,000-record M-Pesa mobile money dataset. Engineered a preprocessing pipeline (cleaning, encoding, stratified train-test split, feature scaling) to handle a realistic 2.9% fraud class imbalance, and tuned each model via GridSearchCV with 2-fold cross-validation. Evaluated models using precision, recall, F1-score, and ROC-AUC rather than accuracy alone, given the imbalanced target. Presented findings — including EDA on fraud patterns by channel, device, and time of day — in a structured report with visualizations and actionable recommendations.
